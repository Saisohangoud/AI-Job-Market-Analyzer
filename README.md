# AI Job Market Analyzer

## Overview
This project analyzes global AI job market trends and predicts salaries using Machine Learning.

## Features
- Salary prediction
- AI job trend analysis
- Country-wise hiring analysis
- Data visualization
- Machine Learning model

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Model
Random Forest Regressor

## Dataset
Global AI Job Market & Salary Trends 2025 Dataset

## Project Output
- Predicts AI salaries
- Shows top hiring countries
- Visualizes top AI roles
